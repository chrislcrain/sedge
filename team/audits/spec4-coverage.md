## Highest-priority gaps

These are the three §4 deviations the Planner should weight most heavily
in the next epic, ordered by user-visible impact.

1. **§4.2 — auto-resume heuristic is over-eager.**
   `HasClaudeHistory(wtPath)` in internal/project/recycle.go:92 returns
   true whenever the encoded-cwd dir under `$CLAUDE_CONFIG_DIR/projects/`
   has *any* directory entry. SPEC specifically says "contains JSONL
   session history". A stub `.lock`, settings file, or partial write
   triggers `--continue` against no real session, which is exactly the
   failure mode SPEC §5.4 invariant exists to prevent. Fix: filter
   `entries` to those matching `*.jsonl` (or with non-zero size) before
   returning true. This is the gap most likely to surface in case 04
   (currently being authored by Tester for §5.4).

2. **§4.5 — `PreCompact` hook is never installed.**
   `hookstate.EventPreCompact` is declared (internal/hookstate/hookstate.go:37)
   and Classify treats it as idle, but cmd/sedge/hook.go:64 `hookEvents`
   list (consumed by `injectSedgeHooks`) does not include it. SPEC §4.5's
   classification table lists `PreCompact` under idle. Result:
   `sedge install-hooks` writes an entry-set that silently drops the
   event, so a long compaction would leave the indicator in whatever
   stale state preceded it. Fix: append `EventPreCompact` to
   `hookEvents`.

3. **§4.5 — staleness threshold is hard-coded, not config-driven.**
   `internal/hookstate/hookstate.go:110` pins `staleAfter = 10 * time.Minute`
   in source. SPEC §4.5 names "> 10 min old" as a *behavioural* invariant
   tied to the classifier; that's fine as a default, but the invariant
   is silently un-tunable today. Promote it to a `config.toml` field
   (`hook_stale_minutes`, default 10) so the SPEC's stated threshold
   becomes observably user-overridable — and add a §4.5 sub-clause to
   document it. Lower priority than the above two, but flagged because
   the test harness (case 09) will eventually need to exercise the
   staleness boundary and a hard-coded 10-minute wait is unacceptable in
   CI.
